# shopping-website
Pretty Chaos is my first web development project, created as I began exploring the world of programming and web design.
As a beginner, I learned HTML and CSS from scratch for the very first time and applied my knowledge by building this clothing brand website. Along the way, I also explored JavaScript to bring interactive features to the website.
Pretty Chaos – A stylish front-end e-commerce clothing website built using HTML, CSS, and JavaScript. Features a modern shopping interface, product collections, Add to Cart functionality, dynamic cart total, and a checkout/payment interface.
